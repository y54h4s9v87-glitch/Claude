1. Open https://business.facebook.com. Use the account switcher at the top left to select the Page **{handle}**. {login_hint}
2. For a vertical short video click **Create reel**; for a horizontal video click **Create post** and add the video.
3. In **Share to / Post to**, tick the Facebook Page **{handle}** only (untick Instagram).
4. Add the job's file from desktop and wait for the upload to finish.
5. Paste the job's CAPTION into the text box. If there is a separate **Title** field, paste the job's TITLE there.
6. Under **Scheduling options**, choose **Schedule**, set the job's date and time, and click **Schedule** (never *Publish now*).
7. Confirm it appears in **Planner** at the right time. Put the link if shown, otherwise `scheduled-in-business-suite` as the result URL.
